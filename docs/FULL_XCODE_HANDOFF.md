# CozyTime Full Xcode Handoff

## Current State

This workspace now has two build paths:

- SwiftPM fallback: fast domain tests with JSON persistence for non-Xcode checks.
- Full Xcode path: `CozyTime.xcodeproj` generated by XcodeGen with SwiftData persistence, asset catalogs, unit tests, UI tests, and release scripts.

Full Xcode is installed and selected. Xcode build, XCTest, XCUITest, SwiftData macro compilation, asset catalog compilation, archiving, codesign verification, menu bar rendering, and screenshot smoke verification have been run on this machine.
